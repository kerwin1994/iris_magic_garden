# Iris’s Magic Garden · 艾瑞丝的魔法花园

面向约 3 岁孩子的英文互动小游戏。柔和的绘本插画，水果、动物、颜色三个环节，共九个任务。无安装依赖、无账号、无后端。

## 直接玩

双击项目根目录的 `index.html` 即可在浏览器打开。推荐 Chrome 或 Safari，并开启设备音量。

也可以使用 Node.js 启动本地服务：

```sh
cd /Users/kerwin/Workspace/donat_ai/iris_magic_garden
npm run dev
```

打开 http://127.0.0.1:5173 。不需要运行 npm install。

## 构建

`npm run build` 生成独立静态文件到 dist；`npm run preview` 预览构建结果。运行脚本仅使用 Node.js 内置模块。

## 玩法

- 点击 Let’s play，依次完成水果、动物、颜色三个环节。首页也能选择起始环节。
- 听英文提示，点击对应物品。答错会温柔重复提示；停留八秒会出现提示动画。
- 答对后点击继续。完成后进入开花的花园，没有分数、倒计时或失败惩罚。
- 点击 Listen again 重听。可用 Tab 和 Enter 操作。
- 长按右上角齿轮约 1.4 秒进入家长设置；键盘可持续按住 Enter。可切换中文辅助提示、英文语音和背景音乐。Esc 关闭设置。

## 技术与声音

采用原生 JavaScript、CSS 与内嵌 SVG，资源无需下载外部依赖。`src/app.js` 是应用源码，`src/style.css` 是样式，`scripts/` 包含服务和构建工具。

英文使用浏览器 SpeechSynthesis，优先选择 en-US Samantha 音色；设备需要有可用的英文语音。不同浏览器的声音与离线能力取决于系统和浏览器，若没有声音，请点击重听并确认英文语音开关及系统音量。背景音乐为 Web Audio 合成，默认关闭。

本环境无法下载 npm 依赖，系统预生成语音也没有输出有效音频，因此本版本采用无依赖网页与浏览器语音实现。未配置离线安装或服务工作线程。

只在浏览器本地保存中文提示和语音开关，不使用麦克风，不上传游戏数据。

## 通关纪念动画

通关后点击「生成我的花园动画」，可播放 26 秒的小故事。点击「生成可下载视频」后等待生成完成，再播放或下载。动画根据本轮实际完成的单词生成；例如从颜色环节进入并完成后，纪念动画仅回顾颜色词。

视频包含绘本动画、英文字幕及可选的合成音乐，不包含英文人声。生成不调用摄像头、麦克风或屏幕录制权限，也不上传内容。浏览器支持时优先导出 MP4，否则选择 WebM；若不支持录制，仍可播放动画预览。生成期间保持页面可见，切换到后台将中止生成并提示重试。关闭弹窗会取消生成、释放媒体轨道及临时文件地址。

源码 `src/film.js` 负责动画与导出。执行 `npm test` 检查纪念内容与导出格式选择；执行 `npm run build` 会将动画模块一起打包。

验证状态：构建、无依赖单元测试及模拟 DOM/录制流程检查已通过。本执行环境无法启动真实浏览器，因此实际视频编码、播放、音画与下载效果仍需在目标浏览器验证。
